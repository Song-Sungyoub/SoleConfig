SOLECONFIG · UI DESIGN REVIEW

값이 어디에 속하는지, 어떻게 보여줄까요?

동일한 JSON을 세 가지 구조로 표현했습니다. 2·3·4단계의 값이 섞여 있습니다. 행을 클릭하면 아래에서 전체 경로를 확인할 수 있습니다.

A · 비교·편집 중심속성과 값의 열 위치를 고정하고, 행 전체 색과 연결선으로 깊이를 표시합니다.
장점: 여러 값을 세로로 비교하기 좋음.
한계: 같은 깊이의 다른 그룹은 연결선을 따라 확인.
B · 구조 파악 중심Unity 예시처럼 깊어질수록 오른쪽 단계 열로 이동합니다. 속성의 다음 단계 칸에 값을 배치합니다.
장점: 깊이와 값의 위치가 직접 대응.
한계: 깊거나 긴 데이터에는 가로 스크롤 필요.
C · 소속 파악 중심 · 추천부모를 구역 제목으로 고정하고, 그 안에 직속 값과 하위 그룹을 배치합니다.
장점: 값이 어느 그룹 소속인지 가장 명확.
한계: 세로 공간을 더 사용하고 그룹 간 비교는 느림.
설계 비교용 목업 · 실제 파일 저장·암호화 기능 없음 · 색은 깊이, 테두리와 연결선은 소속을 표현합니다.
