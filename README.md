# SoleConfig 1.5.0

## 1.5.0: 공개 배포와 GitHub 업데이트

SoleConfig의 Store 메뉴·앱 정보 연결·내장 모듈 참조를 제거했습니다. 자체 업데이트 기능은 유지하며, 스크립트 실행 환경 오류도 자체 업데이트로 안내합니다. 아래 SoleStore 관련 버전 기록은 과거 배포 내용입니다.

## 1.4.3: 새 파일 메뉴 및 값 선택 수정

- 새 파일 형식 선택을 하위 메뉴로 변경하여 잠깐 나타났다 닫히는 문제를 수정했습니다.
- 그룹 행을 지나 위·아래로 이동해도 값 열 선택을 유지합니다.
- 파일 열기 전 50 MiB 초과 파일을 안내하고 중단하는 보호가 포함됩니다. 대용량 부분 조회는 아직 지원하지 않습니다.

## 1.4.2: 모든 탭 닫기

- 탭 우클릭 메뉴에서 현재 창의 모든 탭을 닫을 수 있습니다.
- 미저장 변경은 저장 여부를 확인하며, 취소·저장 실패 시 모든 탭을 유지합니다. 다른 창의 탭은 닫지 않습니다.

## 1.4.1: 셀 복사 및 실행 안내 개선

- 셀 값 편집 중 Ctrl 키 자체를 눌렀을 때 입력이 확정되던 원인을 수정했습니다. Ctrl+C 및 Ctrl+방향키 사용 중 편집과 선택을 유지합니다.
- 스크립트 실행 전 경고 팝업을 제거하고 Beta 설정 아래 짧은 안내로 이동했습니다.

## 1.4.0: 스크립트 값 변환 (Beta)

- 환경 설정 → Python 스크립트 변환 (Beta)을 켜면 메뉴가 표시됩니다. 기본 꺼짐이며 Python 별도 설치는 필요 없습니다. 실행 환경 확인 실패 시 SoleConfig 업데이트·재설치를 안내합니다.
- 셀에서 바로 수정 중 Ctrl+C로 선택한 텍스트를 복사하도록 보강했습니다.
- 셀 우클릭 또는 도구 → 스크립트로 변환…에서 Python 코드를 실행합니다. 입력 문자열은 `value`, 최종 결과는 `result`입니다.
- 보관함의 기본 예제는 사본으로 저장합니다. 사용자 스크립트는 `%LOCALAPPDATA%/SoleConfig/Scripts`에 저장하며 다른 값에서도 재사용합니다.
- 미리보기는 문서 값을 바꾸지 않습니다. 결과 복사 또는 확인 후 값에 적용을 선택합니다. 자료형은 유지하며 기존 Ctrl+Z로 적용을 되돌릴 수 있습니다.
- Python 3.13.15 x64 실행 환경과 라이선스를 앱에 포함합니다. 표준 라이브러리를 사용할 수 있으며 pip/외부 패키지 설치는 제공하지 않습니다.
- 실행 5초, 메모리 256 MiB, 입력/결과 각 1 MiB, 진단 출력 64 KiB 제한입니다. 중지 또는 창 닫기 시 실행 프로세스와 자식 프로세스를 정리합니다.
- Python은 현재 사용자 권한으로 실행합니다. 파일·네트워크 접근을 차단하는 샌드박스가 아니며, 스크립트의 외부 부작용은 문서 실행 취소로 복구되지 않습니다.
- Ctrl+Enter 실행, Ctrl+S 스크립트 저장, Esc 실행 중지. 코드의 Tab은 4공백, Ctrl+Tab은 다음 컨트롤로 이동합니다. 다중 셀 변환과 미저장 코드의 비정상 종료 자동 복구는 포함하지 않습니다.
- [상세 설계와 구현 기록](SCRIPT-TRANSFORM-DESIGN.md)

## 1.3.4: 최신 SoleStore 포함

- 최신 공통 SoleStore 모듈과 전용 화면 스타일을 포함해 업데이트합니다. 기존 SoleConfig 편집 기능과 탭 병합 오류 수정을 유지합니다.

## 1.3.3: 탭 병합 안정화와 SoleStore 갱신

- 마지막 탭을 다른 창에 합친 뒤 닫힌 원래 창의 좌표를 계산하여 앱이 종료되던 오류를 수정했습니다. 미저장 내용과 실행 취소 이력을 유지합니다.
- 최신 SoleStore를 포함합니다. 앱 검색, 사진 갤러리·확대, 리뷰 수정·삭제·도움돼요와 개선된 상세 화면을 제공합니다.
- 기존 카탈로그와 신규 v2 카탈로그를 모두 지원합니다. 이번 앱 업데이트에서 공유 카탈로그 형식은 변경하지 않습니다.

## 1.3.2: 메뉴와 환경 설정 정리

- 탭 아래 도구 모음에 파일 메뉴·현재 보기/원문·실행 취소/다시 실행·구조 편집·도구를 배치합니다. 새 파일/열기/최근 파일/저장/다른 이름 저장은 파일 메뉴에 있습니다.
- 설정 → 환경 설정에서 테마·창 버튼 위치·Beta 옵션을 변경합니다. 즉시 반영·저장하며 저장 실패는 창 안에 표시합니다. Store·업데이트·앱 정보는 설정 메뉴에 유지합니다.
- 보기 메뉴는 단계/트리/그룹 순서입니다. 화면 비교는 트리/단계/그룹이며 가운데 단계가 기본·추천입니다. 기존 보기 설정은 유지합니다.
- 값 우클릭 메뉴를 정리하고 일반 모드에서는 구조 편집 시작을 제공합니다. 자료형은 셀 옆 드롭다운으로 변경합니다.
- CSV 헤더/구분자 옵션은 보기 메뉴로 이동하며, 구조 편집 중 행/섹션 추가는 도구 메뉴에서도 접근할 수 있습니다.

## 1.3.1: 편집 중 위·아래 이동

- 직접 편집 Beta에서 입력 중 ↑/↓는 검증·적용 후 이전/다음 값의 편집으로 이동합니다. A/B는 펼쳐진 값 순서, C는 같은 그룹, CSV는 같은 열의 위/아래 행입니다.
- 잘못된 입력은 이동을 막고 초안을 유지합니다. 좌/우는 글자 커서 이동, 한글 조합 중 방향키는 입력기에서 처리합니다.

## 1.3.0: 셀에서 바로 수정 (Beta)

- 일반 모드에서도 JSON/YAML 값의 String·Number·Boolean·Null, XML 단순 값의 String·CDATA를 자료형 드롭다운으로 변경할 수 있습니다. 이름 변경·항목 추가/삭제는 구조 편집 모드에서만 가능합니다. 변환할 수 없는 값은 기존 값·자료형을 유지합니다.

- 설정 → 셀에서 바로 수정 (Beta). 기본 꺼짐, 로컬 저장. A/B/C 한 줄 값은 더블클릭·F2·Enter로 셀에서 편집합니다. 메뉴의 팝업에서 수정도 유지합니다.
- Enter로 검증·적용하고 다음 값을 전체 선택해 편집합니다. Shift+Enter는 이전 값, Tab/Shift+Tab도 연속 값 이동입니다. 마지막 값에서는 멈추며 항목을 자동 추가하지 않습니다.
- A/B는 현재 펼쳐진 검색 결과의 값 순서, C는 같은 부모 그룹의 값 순서로 이동합니다. 그룹·주석·Null은 연속 편집 대상에서 제외합니다. 주석은 직접 선택해 수정할 수 있습니다.
- 선택 상태에서 A는 위/아래 행 이동 및 속성의 좌/우 접기·펼치기, B/C는 속성/값 셀 이동을 지원합니다. C의 이동은 현재 그룹 안으로 제한합니다. 입력 중 좌/우는 글자 커서 이동이며, 1.3.1부터 위/아래는 적용 후 값 이동입니다.
- CSV는 기존 범위 선택·복사/붙여넣기를 유지하고 Beta에서 Enter는 아래 행, Tab은 오른쪽 셀의 편집으로 이어집니다. Shift는 반대 방향이며 자동 표 확장은 하지 않습니다.
- 여러 줄 값은 기존 팝업을 사용합니다. Boolean은 체크박스 또는 Space로 변경하며 Enter로 반전하지 않습니다. 원래 자료형은 입력 모양과 관계없이 유지합니다.
- Esc는 현재 입력 취소, Ctrl+S는 현재 입력 검증·적용 후 파일 저장입니다. 잘못된 숫자는 적용·이동을 막고 입력과 오류 안내를 유지합니다.
- 행 높이와 열 너비는 입력 때문에 변경하지 않습니다. 스크롤로 편집 셀이 화면 밖에 나가면 초안은 보존하고 입력을 일시 중지합니다. Enter/F2 또는 입력 복원으로 돌아가며 Esc로 취소할 수 있습니다.
- 미적용 입력은 기존 작업 복원 정보에 포함됩니다. 기준 문서가 바뀌면 자동 적용을 막고 복원 입력 확인창에서 내용을 복사하거나 정리할 수 있습니다.
- 창 버튼을 오른쪽으로 배치하면 순서를 반전해 닫기 버튼을 바깥쪽 끝에 표시합니다.
- 한글 IME 실제 키 입력과 대용량 업무 파일의 연속 편집 성능은 별도 사용자 환경 확인 대상입니다.

## 1.2.1: 상위 경로 고정 표시와 열 자동 맞춤

- 설정의 상위 경로 고정 표시 (Beta)는 기본 꺼짐이며 단계 보기에서 사용합니다. 헤더 아래 26 DIP를 고정 확보해 화면 밖 부모 경로를 각 단계 위치에 표시합니다.
- 첫 번째 화면 내 데이터 행을 기준으로 주석/추가 행을 제외하며 화면에 보이는 부모는 중복 표시하지 않습니다. 고정 내용은 읽기 전용입니다.
- 열 경계 더블클릭은 현재 펼쳐진 항목(검색 시 결과)의 내용에 맞춰 너비를 조절합니다. 화면 밖 항목도 측정하며 그룹의 다중 열 병합 제목은 제외합니다.
- 헤더/경계 우클릭의 기본 너비로 초기화할 수 있고 드래그로 다시 줄일 수 있습니다. 열 너비 범위는 100~10,000 DIP이며 긴 내용은 가로 스크롤로 확인합니다.
- 고정 행은 헤더와 같은 좌표/배율을 사용해 가로 스크롤과 열 조절에 맞춰집니다.

## 1.2.0: SoleStore 모듈

SoleStore.dll을 포함한 내부 팝업으로 전환했습니다. 설정 → Sole Store에서 공유 카탈로그 기반 검색·설치/업데이트·소개/캡처·버전·리뷰를 제공합니다. PC 이름 기준 리뷰를 작성/수정/삭제하며 이는 계정 인증이 아닙니다. 통계는 관리자용 --sole-store-aggregate 실행 결과를 읽습니다. 상세 통합/운영 방법은 ../SoleStore/README.md를 참고하세요.

## 1.1.1: 백업 정리 및 사용성 개선

- 기존 파일을 처음 저장하기 전 내용은 실행 중 숨김 백업으로 유지합니다. 마지막 창이 정상 종료되면 이번 실행에서 만든 백업을 삭제합니다.
- 비정상 종료·저장 실패의 백업과 실행 전에 존재한 .bak는 보존합니다. 기존 .bak가 있으면 고유 이름의 백업을 생성합니다. 타 프로그램이 변경한 백업은 삭제하지 않습니다.
- 백업 정리가 권한/잠금으로 실패하면 파일이 남을 수 있습니다. 이전 실행의 백업은 자동 삭제하지 않습니다.

- 설정에서 창 버튼 좌우 위치를 선택·저장하고 현재 테마를 체크로 확인합니다. 앱 정보에는 모드별 사용법과 주요 단축키를 안내합니다.
- 설정 또는 앱 정보에서 별도 Sole 앱 창을 엽니다. SolePlan·SoleMD는 기본 사용자/Program Files 설치 경로를 확인해 실행 또는 설치를 제공하며, SoleConfig는 현재 실행 버전을 표시합니다.
- 설치 클릭 시 공유 폴더의 최신 숫자 버전 MSI를 로컬 임시 폴더로 복사하고 SHA-256 일치 확인 후 설치 마법사를 실행합니다. 실제 설치 완료 후 상태를 재확인하며, 사용자 지정 설치 경로는 자동 감지 범위 밖입니다.

- 값 변경 중 기존 표를 유지하고 스크롤 위치를 복원해 true/false 전환 시 화면이 순간적으로 밀리는 현상을 줄였습니다. A/B/C 150개 항목의 값 변경·스크롤 유지 회귀 검사 포함.

- 설정 → SoleConfig 정보에서 앱 아이콘·실행 버전·지원 형식을 확인하고 업데이트 확인을 실행할 수 있습니다.

## 1.1.0: 편집 화면 재배치

- 제목 표시줄·탭·단일 도구 모음으로 상단을 정리하고 중복 파일명/경로 영역을 제거했습니다.
- 설정은 톱니바퀴 아이콘으로 표시하며 업데이트 확인을 설정 메뉴에 통합했습니다.
- 새 파일·열기와 보기 전환을 같은 줄에 배치했습니다. 열기 옆 화살표는 최근 파일, 보기 옆 화살표는 A/B/C 선택입니다.
- 실행 취소/다시 실행·암호화/해시·CSV 헤더/구분자 및 구조 모드 행/섹션 추가는 도구 메뉴에서 사용합니다. 저장 옆 화살표는 다른 이름으로 저장입니다.
- 열린 탭 목록, 긴 탭 제목 말줄임과 경로 툴팁, 탭 우클릭의 경로 복사/위치 열기를 제공합니다.
- 빈 창에 파일 열기·새 파일·최근 파일 진입점을 표시하고 하단 안내 높이를 줄였습니다.
- 최소 창 폭 900px에서 구조 편집 중 도구 모음의 라이트/다크 배치를 확인했습니다. 자체검사 92건과 최종 전체 UI 회귀 검사를 통과했습니다.

## 0.1.14: 스크롤바와 메뉴 테마

- 가로·세로 스크롤바를 얇은 둥근 손잡이와 호버/드래그 강조로 통일하고 기본 화살표와 모서리 배경을 제거했습니다.
- 우클릭·설정 메뉴를 둥근 테마 배경, 일관된 여백, 파란 체크 표시로 변경했습니다. 라이트/다크에 함께 적용합니다.

## 0.1.13: 구조 편집과 CSV 편집

구조 편집·CSV 범위 편집·자료형 색상과 미완료 작업 복원을 포함한 업데이트입니다.

- 일반 모드에서 기존 값·주석을 수정하고, 구조 편집에서 추가·삭제·이름·자료형·순서를 변경합니다. 원문은 일반 모드에서 읽기 전용입니다.
- 구조 편집은 탭별로 관리합니다. 완료는 미저장 문서에 반영, 편집 전체 취소는 진입 전 상태 복구입니다. Ctrl+S는 유효한 추가 입력 확정과 저장을 연결합니다.
- 펼친 그룹 아래의 낮은 추가 행에서 가로 자료형 메뉴와 입력 패널을 엽니다. 리스트의 이전 구조로 추가는 예시만 표시하고, 값까지 복제는 실제 값을 채웁니다.
- 추가 패널을 닫아도 초안은 유지합니다. 상단 추가 입력 계속으로 다시 열 수 있습니다. 미입력과 예시는 저장하지 않습니다.
- 삭제는 예정 상태와 복구를 제공하고 완료/저장에서 반영합니다. 삭제 예정이 남으면 다른 구조 명령은 완료/복구 후 수행합니다.
- 손잡이 드래그로 같은 부모의 순서를 바꿉니다. 위/아래 절반은 앞/뒤 삽입입니다. YAML과 XML 속성·혼합 내용 이동은 원문 편집을 사용합니다.
- CSV는 셀 직접 편집·범위 선택·복사/붙여넣기·Delete 내용 지우기·일괄 Undo를 지원합니다. 일반 복사는 헤더 제외, 우클릭에서 헤더 포함 복사를 선택합니다.
- CSV 헤더는 제목만 굵게 표시합니다. 헤더가 없으면 열 번호만 표시하며 원본에 없는 셀은 —로 구분합니다.
- 표를 넘는 붙여넣기는 일반 모드에서 차단하고 구조 편집에서 확장 확인과 새 헤더 지정 후 적용합니다. 검색 중 범위 수정은 검색 해제 후 수행합니다.
- 자료형 색상, 옅은 행 호버, 드래그 삽입선을 적용했습니다.
- 구조 작업본·추가 초안·삭제 예정과 미적용 값/셀 입력을 로컬 복원합니다. 복원본 버전 1/2를 읽으며 새 기록은 버전 2입니다. 정상 편집창을 닫으면 미적용 입력은 취소됩니다.

검증 범위: 자체검사 및 앱 내 UI 이벤트·렌더 회귀. 실제 Excel 프로그램과의 클립보드 왕복 및 실사용 마우스 드래그는 별도 인수 확인 대상입니다. YAML 앵커·복합 구조와 파일 형식의 기존 지원 경계는 유지합니다.


JSON·XML·YAML·INI 트리 그리드와 CSV 셀 편집을 제공하는 Windows WPF 설정 편집기.

## 실행

- `dist/win-x64/SoleConfig.exe`: 작은 배포본. .NET 8 Desktop Runtime x64 필요. 현재 개발 PC에는 설치되어 있다.
- `dist/portable-win-x64/SoleConfig.exe`: 런타임 포함 배포본. 폴더 전체를 복사해 실행한다.
- 두 배포본 모두 설치 프로그램·관리자 권한을 요구하지 않는다. 쓰기 권한이 있는 설정 파일만 수정할 수 있다.
- `Samples` 폴더에 다섯 형식의 비민감 예제가 있다.

```powershell
.\SoleConfig.exe "C:\configs\application.json" "C:\configs\application.ini"
.\SoleConfig.exe --data "CE1:..."
```

`--data`는 암호문을 변환 창에서 열며 비밀번호는 화면에서 입력한다. 기존 외부 프로그램 암호화 방식의 자동 판별·호환 기능은 없다.

## 편집 흐름

1. 새 파일 또는 열기. 여러 파일을 탭으로 관리하고 파일 드래그 앤 드롭도 가능하다.
2. 트리를 펼쳐 값 더블클릭 또는 F2로 수정한다. 논리값은 체크박스로 전환한다.
3. 자료형 열의 드롭다운에서 JSON·YAML은 String/Number/Boolean/Null, XML 단순 태그 값은 String/CDATA로 변경한다. 잘못된 변환은 원래 값과 자료형을 유지하며 하단에 이유를 표시한다. 실행 취소할 수 있고 파일 저장은 별도다.
   XML 단순 텍스트·CDATA·빈 태그는 태그명과 값을 한 행에 표시한다. 속성은 @이름, 혼합 내용은 순서를 유지한 구조로 표시한다. XML 속성·INI·CSV는 문자열이며 숫자처럼 보이는 값을 자동 변환하지 않는다.
   ⋯ / 오른쪽 클릭에서 이름 변경, 항목 추가·삭제, 암호화·복호화·해시를 선택한다.
4. 원문 편집에서는 전체 내용을 직접 수정한다. 오류가 있으면 원문과 오류 안내를 유지하며 구조 편집과 저장을 막는다.
5. Ctrl+S로 수동 저장한다. 실행 취소 Ctrl+Z, 다시 실행 Ctrl+Y, 찾기 Ctrl+F, 열기 Ctrl+O를 지원한다.

변환 결과는 복사 또는 선택 값 적용을 거쳐 반영된다. 숫자·논리값에 문자열 결과를 적용할 때 자료형 변경을 확인한다. 파일 저장은 별도다.
CSV의 첫 행 헤더 여부와 쉼표·탭·세미콜론 구분자를 선택할 수 있다. 기본적으로 모든 셀은 문자열이며 선행 0을 보존한다. 행/열 추가·삭제는 컨텍스트 메뉴에 있다. 헤더 이름은 헤더 옵션을 해제한 뒤 첫 행 셀을 편집한다.

## 파일과 탭

탐색기에서 파일을 열면 같은 설치 위치에서 실행 중인 SoleConfig의 마지막 활성 창에 탭으로 추가된다. 이미 연 파일은 해당 탭을 선택한다. 설치본과 다른 폴더의 이동용 실행본은 별개로 동작한다.

탭을 좌우로 끌어 순서를 바꾸고, 다른 SoleConfig 창의 탭 표시줄에 놓으면 합쳐진다. 탭 표시줄 밖으로 끌어 놓으면 새 창으로 분리되며 Esc로 취소할 수 있다. 탭 오른쪽 클릭의 새 창으로 이동 / 다른 창으로 이동 메뉴도 제공한다. 미저장 내용·실행 취소·인코딩·검색·접힘을 유지하며 마지막 탭을 옮긴 빈 창은 닫힌다.

이 기능은 0.1.7부터 제공한다. 구버전 창은 변경 내용을 저장하고 닫은 뒤 새 버전에서 다시 연다.

## 보기 설정

보기 설정이 없는 첫 실행에는 트리·단계·그룹의 실제 화면을 비교한다. 가운데 단계 보기가 기본·추천이며 선택 생략 시 단계로 시작한다. 기존 설정은 유지한다. 보기 메뉴의 화면 예시로 선택에서 다시 비교할 수 있다.

상단 **설정**에서 A 트리 보기·B 단계 보기·C 그룹 보기를 선택한다. 기본은 B이며 다음 실행에도 선택을 유지한다. A는 속성/값 고정 열과 행 전체 단계색, B는 단계별 열과 속성 바로 다음 열의 값, C는 부모별 중첩 카드로 표시한다. B의 값 칸은 라이트에서 흰색, 다크에서 기본 표 배경을 사용한다.

보기 전환은 원문·변경 상태·실행 취소 이력·선택 경로·검색·접힘을 유지한다. CSV는 항상 기존 표를 사용한다. 같은 설정 메뉴에서 테마를 바꿀 수 있다. C는 펼쳐진 항목을 모두 렌더하므로 큰 파일은 가상화된 A/B 보기를 권장한다.

편집 영역에서 **Ctrl+휠**로 50~200% 범위에서 10%씩 확대·축소한다. **Ctrl+0** 또는 하단 배율 버튼을 누르면 100%로 돌아간다. Ctrl+더하기/빼기도 지원한다. 세 보기·CSV·원문 편집에 같은 배율을 적용하며, 새 실행은 100%로 시작한다.

## 저장 보호

- 값 수정은 원문 범위를 교체하여 수정하지 않은 공백·주석·개행·XML 인용부호·CSV 필드를 유지한다. 구조 추가 위치의 공백은 새로 작성된다.
- 변경 없는 저장은 원본 바이트를 유지한다. 기존 파일을 교체할 때 직전 원본 하나를 `.bak`에 보관한다. 백업에는 원본 평문도 포함될 수 있다.
- 로드 시 파일 해시와 저장 직전 해시를 비교하여 외부 변경·삭제를 감지한다. 충돌 시 다른 이름으로 저장하거나 탭을 닫고 다시 연다.
- 같은 디렉터리의 임시 파일에 기록한 뒤 원자적 파일 교체를 사용한다. 파일 시스템이 교체를 지원하지 않으면 실패를 표시한다.
- UTF-8·UTF-16·UTF-32 BOM을 읽고 유지한다. BOM 없는 UTF-8 디코딩 실패 시 CP949 재열기를 선택한다. 인코딩 변경은 다음 저장에 적용된다.
- XML 선언의 인코딩과 실제 저장 인코딩이 다르면 저장을 거부한다.
- 변경 후 탭·창 닫기에는 저장·버리기·취소를 제공한다.

## 암호화와 해시

- 자체 형식 `CE1:` + Base64. AES-256-GCM, PBKDF2-HMAC-SHA256 600,000회, 랜덤 salt 16바이트, nonce 12바이트, 태그 16바이트. AAD는 ASCII `CE1`.
- Base64 내부 순서는 `salt | nonce | tag | ciphertext`. 평문은 UTF-8이며 정규화·공백 제거 없이 처리한다.
- SHA-256은 UTF-8 입력에 대해 Hex 또는 Base64 결과를 제공한다. 복호화 기능은 없다.
- 비밀번호를 설정·로그에 저장하지 않으며, 파생 키와 작업용 평문 바이트는 사용 후 지운다. .NET 문자열의 메모리 완전 소거는 보장하지 않는다.
- HTML 목업의 `DEMO:`와 기존 타 프로그램의 암호문은 호환되지 않는다. 기존 암호화 함수/시험 벡터를 받으면 별도 호환 프로필을 추가해야 한다.

## 현재 지원 경계

- 엄격한 JSON 문법을 사용한다. JSONC·중복 JSON 키는 오류로 처리한다.
- YAML 앵커·별칭·명시적 태그·복합 키·블록 문자열과 일부 흐름 스타일 구조 변경은 원문 편집으로 연결한다. 단순 값 수정과 일반 블록 매핑 추가·삭제는 그리드에서 가능하다.
- INI는 `key=value`/`key:value`와 전체 줄 `;`/`#` 주석을 지원한다. 인라인 주석과 여러 줄 값은 방언을 임의 추측하지 않는다.
- XML DTD는 사용하지 않는다. 네임스페이스 선언·이름 변경은 원문 편집을 사용한다.
- CSV는 행별 열 수를 자동 보정하지 않는다. 실제 없는 셀은 원문 편집으로 추가한다.
- 속성 의미·허용 범위의 스키마 검증, 파일 전체 암호화, 무화면 변환, 코드 서명은 미포함이다.
- 파싱은 백그라운드에서 수행하며 결과가 오래되면 버린다. 편집 이력은 전체 원문 최대 30개이므로 대용량 파일에서는 메모리 사용이 증가한다. 대용량 성능 한계는 아직 측정하지 않았다.

## 자동 업데이트

- 공개 저장소 Song-Sungyoub/SoleConfig의 최신 정식 Release를 확인한다. 태그는 v1.5.0, 파일명은 SoleConfig-1.5.0-x64.msi 형식이다. 초안·베타·현재 이하 버전은 설치하지 않는다.
- GitHub asset의 SHA-256과 파일 크기, MSI 제품명·제조사·UpgradeCode·버전을 검증한 뒤 설치한다. GitHub 토큰은 사용하지 않는다.
- API 확인은 15초, 다운로드는 5분 제한이다. 수동 확인 시 릴리즈 부재·요청 한도·연결 오류를 표시하며 자동 확인 실패는 편집을 방해하지 않는다.
- 기본 설치 위치에서만 업데이트한다. 설치 전 열린 창·탭과 미저장 내용을 보관하고 다시 실행할 때 복원한다. 설치 로그와 다운로드 파일은 로컬 Updates 폴더에 남긴다.
- 기존 1.4.3 이하 버전은 이전 업데이트 경로와 제조사 검증을 사용하므로 1.5.0 MSI를 한 번 직접 설치해야 한다. UpgradeCode와 설치 위치는 유지한다.
- SHA-256은 게시 파일과의 일치 검사이며 게시자 코드 서명을 대신하지 않는다. 설치 파일에는 코드 서명이 없다.

### Windows 설치 파일

`dist/SoleConfig-1.5.0-x64.msi`는 .NET 런타임을 포함한 현재 사용자용 x64 설치 파일이다. 기본 위치는 `%LocalAppData%\Programs\SoleConfig`이며 시작 메뉴의 SoleConfig 바로가기를 등록한다. Windows 설정의 설치된 앱에서 제거할 수 있다. 사용자가 별도로 저장한 설정 파일과 테마 설정은 제거하지 않는다.

설치 완료 화면에는 `SoleConfig 실행`(기본 선택)과 `기본 프로그램 설정 (Windows 설정 열기)`(기본 해제)를 제공한다. 선택하면 별도 안내창 없이 Windows 기본 앱 설정을 연다. JSON·XML·CSV·YAML·YML·INI를 지원 형식으로 등록하며 실제 기본 앱 변경은 사용자가 Windows 설정에서 확정한다. 기존 기본 앱 연결은 자동 변경하지 않는다. 시작 메뉴 바로가기는 기본 등록한다.

설치 파일 생성: `./Installer/Build.ps1` (PowerShell 7, .NET SDK 필요). WiX 5.0.2와 같은 버전의 UI 확장을 준비한 뒤 런타임 포함 배포본을 MSI로 묶는다. `/qn` 무인 설치에서는 완료 화면·앱 실행을 표시하지 않는다. 회사 코드 서명은 아직 적용하지 않았다.


```powershell
.\build.ps1
.\build.ps1 -Portable
.\bin\Release\net8.0-windows\SoleConfig.exe --self-test
.\bin\Release\net8.0-windows\SoleConfig.exe --ui-test "C:\temp\soleconfig-ui-test"
```

자동 검사: 형식별 원문 보존, Unicode·큰 숫자·중복 키, 추가/삭제/이름 변경, CSV·YAML·XML 특수 값, 암호화 왕복·변조·오류 키, SHA 벡터, 백업·외부 변경·인코딩.

값·주석 수정 창을 연 동안 뒤쪽 편집 영역은 마우스 휠과 스크롤바로 참고할 수 있다. 배경 클릭·단축키·탭 이동은 차단하며 외부 파일 열기는 수정 창을 닫은 뒤 처리한다. 적용은 처음 선택한 항목에만 수행하고 편집 중 문서가 바뀌면 적용하지 않는다.

## 최근 파일과 작업 복원

- 최근 파일 버튼에서 최근 열거나 저장한 파일 20개를 다시 연다. 목록 지우기는 원본 파일을 삭제하지 않는다.
- 열려 있는 창별 탭, 파일 경로, 미저장 원문, 인코딩, 선택 탭, 검색·접힘 상태를 사용자 LocalAppData의 SoleConfig/Workspace 아래에 보관한다. 실행 위치별로 분리하며 설치 경로가 같은 업데이트에서는 유지된다.
- 2초 간격으로 변경된 복원본을 기록하고, 창 종료·업데이트 직전에 즉시 기록한다. 원본 파일을 자동 저장하지 않는다. 일반 종료에는 미저장 탭도 보관하며 명시적으로 탭을 닫을 때는 저장 여부를 확인한다.
- 복원본 저장 실패 시 정상 종료·업데이트를 중단한다. 비정상 종료 시 마지막 기록 이후 약 2초의 작업은 복원되지 않을 수 있다. 수정 팝업에서 아직 적용하지 않은 입력 및 실행 취소 이력은 복원 대상이 아니다.
- 수정하지 않았던 파일은 재실행 시 디스크의 최신 내용으로 읽는다. 미저장 내용은 복원 당시 기준 파일 해시를 유지해 외부 변경을 덮어쓰지 않는다. 원본이 없어도 남은 복원본을 열 수 있다.
- 복원 파일이 손상되면 직전 백업을 시도하고 복구 문제를 안내한다.
- 이 기능이 없는 구버전에서 최초 업데이트할 때는 기존 미저장 파일을 먼저 저장해야 한다. 복원은 이 기능이 포함된 버전에서 작업한 시점부터 가능하다.
## 0.1.12 변경 사항

- 최근 파일 20개 목록, 열린 창·탭 및 미저장 원문 로컬 복원.
- 정상 종료·업데이트 전 복원본 기록, 외부 원본 변경 보호 및 복원본 백업.
- 문법 오류 상세 팝업에 파일·행/열·주변 원문 표시와 오류 위치 이동.
- 값·주석 수정 창을 연 동안 배경 표 스크롤 허용, 다른 조작 차단.
- 구버전에서 이번 버전으로 처음 업데이트하기 전에는 미저장 파일을 먼저 저장해야 한다.
검색창은 기본적으로 숨겨져 있으며 Ctrl+F로 열고 입력칸에 포커스를 둔다. Esc 또는 ×로 닫으면 검색 조건을 해제한다. 검색 조건이 남은 탭이나 복원된 작업은 검색창을 표시해 필터 상태를 알 수 있게 한다.

검색창은 크롬 찾기 창처럼 편집 영역 오른쪽 위에 떠 있는 패널로 표시되며 표의 크기를 바꾸지 않는다. 상단 전체 펼치기·접기 버튼은 제거했다. 각 항목 화살표를 클릭하면 해당 항목을 펼치거나 접고, Alt를 누른 채 클릭하면 모든 하위 그룹까지 함께 펼치거나 접는다(A/B/C 공통).

탭 우클릭 메뉴의 ‘모든 탭 닫기’는 현재 창의 탭만 닫는다. 미저장 탭은 기존 저장 확인을 거치며, 취소하거나 저장에 실패하면 탭을 닫지 않는다. 다른 창은 유지하고 완료 후 열린 탭 복원 상태를 갱신한다.


## 초대용량 파일 열기 보호

파일 내용을 읽기 전에 같은 파일 핸들의 길이를 확인하여 50 MiB 초과 파일은 안내 후 열지 않습니다. 기존 탭은 유지합니다. 10GB 편집 지원은 포함하지 않으며, 50 MiB 이하여도 복잡도에 따른 성능 한계는 있습니다. 크기 경계·10 GiB 길이 판정 및 한도 초과 실제 파일 거부를 포함한 자체 검사 146건 통과.
